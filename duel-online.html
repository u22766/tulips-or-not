How to play

You and your opponent each hide a five-letter word on your own phones. A coin toss decides who goes first, then you take turns guessing. After every guess you get back two numbers.

2:1 means two letters are correct and in the right spot, and one more letter is in the word but in the wrong place.

Repeated letters count only as often as they appear: hidden word SPEED, guess GEESE → 1:2. First to name the other's word wins.

⚙ One-time setup needed

This page needs a free Firebase project to relay moves between phones. Ten minutes, no credit card:

  1. Go to console.firebase.google.com, sign in with Google, and create a project (any name).
  2. Choose Build → Realtime Database → Create database, any region, start in locked mode.
  3. In the database's Rules tab, replace everything with the rules below and publish.
  4. Go to Project settings → General → Your apps, add a Web app (</> icon), and copy the config values.
  5. Open this HTML file in a text editor, find FIREBASE_CONFIG near the top of the script, and paste your values in.
  6. Re-upload the file to GitHub. Done — this screen disappears.

Database rules (copy–paste)

{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      "$code": {
        ".read": "$code.matches(/^[A-Z0-9]{6}$/)",
        ".write": "$code.matches(/^[A-Z0-9]{6}$/)",
        ".validate": "newData.hasChild('created')",
        "created": { ".validate": "newData.isNumber()" },
        "status":  { ".validate": "newData.isString() && newData.val().length < 12" },
        "turn":    { ".validate": "newData.isString() && newData.val().length < 6" },
        "winner":  { ".validate": "newData.isString() && newData.val().length < 6" },
        "wins":    { "host": { ".validate": "newData.isNumber()" },
                     "guest": { ".validate": "newData.isNumber()" } },
        "toss":    { "call":    { ".validate": "newData.isString() && newData.val().length < 6" },
                     "outcome": { ".validate": "newData.isString() && newData.val().length < 6" } },
        "host":    { "name":   { ".validate": "newData.isString() && newData.val().length <= 12" },
                     "secret": { ".validate": "newData.isString() && newData.val().length <= 12" },
                     "online": { ".validate": "newData.isBoolean()" } },
        "guest":   { "name":   { ".validate": "newData.isString() && newData.val().length <= 12" },
                     "secret": { ".validate": "newData.isString() && newData.val().length <= 12" },
                     "online": { ".validate": "newData.isBoolean()" } },
        "moves":   { "$i": { "who":  { ".validate": "newData.isString() && newData.val().length < 6" },
                             "word": { ".validate": "newData.isString() && newData.val().length == 5" },
                             "ex":   { ".validate": "newData.isNumber()" },
                             "mis":  { ".validate": "newData.isNumber()" },
                             "hit":  { ".validate": "newData.isBoolean()" },
                             "$other": { ".validate": false } } }
      }
    }
  }
}

These rules only allow reads/writes inside six-character game rooms with the exact fields the game uses, nothing else. No personal data is stored — just names players type, words, and guesses. Rooms are overwritten as codes get reused.
